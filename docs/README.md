# Documentation

addrck checks email syntax and compares SMTP responses for a recipient and a
random probe address. Start with [installation](installation.md), then follow
the [usage guide](usage.md) to run a check and interpret its result.

| Guide | Covers |
| --- | --- |
| [Installation](installation.md) | Python requirements, uv and pip setup, and network access. |
| [Usage](usage.md) | CLI options, examples, output streams, and exit statuses. |
| [How validation works](validation.md) | DNS fallback, SMTP command flow, and limits of the result. |
| [Troubleshooting](troubleshooting.md) | Input errors, DNS failures, unreachable servers, and inconclusive results. |
| [Development](development.md) | Source layout, internal functions, testing, and making changes. |

Return to the [project README](../README.md) for the quick start and license.
